# Apuntes de JavaScript.

Este apunte habla sobre el lenguaje de programación JavaScript y busca brindar los conocimientos teóricos detrás de dicho lenguaje. Queda en el lector practicar todos los conceptos aquí vistos.

1. Agregar una lección sobre arrays (En curso).
2. Agregar una lección sobre objetos.
3. Agregar una lección sobre funciones.
4. Agregar lecciones de programación orientada a objetos.
5. Agregar una lección sobre bitwise.
6. Agregar una lección sobre algunas estructuras de datos definidas por defecto como el `Map` o el `Set`.
7. Agregar una lección sobre programación funcional.
8. En la `Lección 12 (Funciones)` hablar sobre la `recursión a la cola`.
9. Hablar en algún lugar sobre el operados `?.` para acceder a métodos y funciones de objetos.
