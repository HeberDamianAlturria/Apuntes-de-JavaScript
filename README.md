# Apuntes de JavaScript.

Este apunte habla sobre el lenguaje de programación JavaScript y busca brindar los conocimientos teóricos detrás de dicho lenguaje. Queda en el lector practicar todos los conceptos aquí vistos.

1. Agregar una lección sobre bitwise.
2. Agregar una lección sobre algunas estructuras de datos definidas por defecto como el `Map` o el `Set` (En curso).
3. Agregar una lección sobre programación funcional.
4. En la `Lección 12 (Funciones)` hablar sobre la `recursión a la cola`.
5. Hablar en algún lugar sobre el operados `?.` para acceder a métodos y funciones de objetos.
6. Agregar en la `Lección 12 (Funciones)` hablar sobre la `funciones generadoras`.
7. Agregar en la `Lección 15` hablar sobre las `Inner Class`.
